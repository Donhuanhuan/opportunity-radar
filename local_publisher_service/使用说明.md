# 本地内容发布服务

## 这是什么

一个跑在**你电脑上的** Node.js 微服务。复用你**已登录的 Microsoft Edge 浏览器数据**（用户目录），所以**无需导出 cookie、无需扫码登录**——直接就能发小红书/知乎。

## 为什么用本机服务（不是云端 Playwright）

| 风险 | 云端 Playwright | 本机服务 |
|---|---|---|
| IP | 数据中心（异地 IP） | 你家 IP（跟平时登录一致） |
| 浏览器指纹 | 全新 Chromium | 你 Edge 的真实指纹 |
| Cookie | 每次都需新登录 | 复用你 Edge 已登录态 |
| 封号风险 | 🟡 中 | 🟢 最低 |

## 一键安装

文件位置：`D:\WorkBuddy\Make monney\Make monney\opportunity-radar\local_publisher_service\`

**双击 `install.cmd`**（装 playwright + express，一般 1~3 分钟，视网络波动可能更久；中途黑窗显示 `✅ 依赖安装完成` 即成功，装完按任意键关闭）

## 一键启动

**双击 `start.cmd`**（文件同上）

会弹出一个**黑色命令行窗口**，里面显示：
```
本地发布服务已启动: http://localhost:19000
Edge 路径: C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
Edge 用户数据: C:\Users\30689\AppData\Local\Microsoft\Edge\User Data
模式: 有窗口（推荐首次用有窗口看登录态）
```

**保持这个窗口开着**——它就是你电脑的"小机器人后台"。你最小化它就行，不用关。

## 我怎么调用它

我会在你电脑上发 HTTP 请求到 `http://localhost:19000/publish`，传 JSON：

```json
{
  "platform": "xiaohongshu",
  "title": "AI 工具变现：从 0 到 1 的 30 天",
  "body": "正文内容...",
  "tags": ["AI", "副业"],
  "dryRun": false
}
```

服务会用你 Edge 的已登录态打开小红书/知乎，按真人节奏（2-8s 间隔）填内容、点发布。

## 健康检查

```bash
curl http://localhost:19000/health
```

返回 `{"ok":true,"edge":true,"userData":true}` 就说明一切正常。

## 何时需要重启服务

- 改了 `index.js` 后
- 想要更换平台/账号时
- Edge 自动更新后需要重新走登录态

## 故障排查

| 现象 | 原因 | 解法 |
|---|---|---|
| `Edge 路径不存在` | 没装 Edge | 安装 Edge（Win10/11 默认有） |
| `Edge 用户数据不存在` | Edge 第一次没启动过 | 先打开一次 Edge |
| 页面显示"未登录" | Edge 登录态掉了 | 打开 Edge 重新登录 |
| Playwright 下载超时 | 默认源在国外 | install.cmd 已配 npmmirror |

## 高级开关

| 环境变量 | 默认值 | 作用 |
|---|---|---|
| `PORT` | 19000 | 监听端口 |
| `HEADLESS` | false | false=有窗口（推荐首次），true=无窗口（生产） |
| `EDGE_EXE` | 自动检测 | Edge 可执行文件路径 |
| `EDGE_USER_DATA` | 自动检测 | Edge 用户数据目录 |

## 与商机雷达（M1/M2/M3）的关系

```
M1 scan（抓商机，落盘 data/opportunities.jsonl）
   → agents.orchestrator（DeepSeek 3-Agent：选品→润色→合规）→ 写飞书「内容审核」表=待审
   → 欢欢在飞书把状态改成「通过」
   → audit_gate（python -m radar.publish.audit_gate --poll）
   → 调本机服务 http://localhost:19000/publish → Edge 真发
```

本服务只负责最后一步「真发」。前面 M1/M2/M3 脚本由机会雷达定时任务触发，无需本窗口。
